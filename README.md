# 深度学习期末 150 题复习助手

一个可直接分享的纯静态复习网页，包含单选题、程序设计题、填空题、编程题、判断题、简答题和计算题。

## 在线使用

GitHub Pages 部署完成后，可直接访问：

<https://qzjjimmy.github.io/deep-learning-review/>

无需安装软件或登录。

## 功能

- 按题型查看全部题目
- 题型练习序号从 1 重新开始，并同时显示原题号
- 固定在页面底部的分题型进度与正确率统计
- 按题号、题干和选项搜索
- 单选题和判断题逐题作答
- 每道题的答案下方都附有对应解析
- 答案与作答状态在当前页面中保留
- 一键展开或收起当前题型的全部答案
- 一键复制参考答案
- 手机与电脑自适应布局

## 说明

题库和答案依据用户提供的《深度学习-150.pdf》完整整理稿制作。网页不包含原 PDF 中的个人作答记录。
